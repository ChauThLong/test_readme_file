## ⚙️ Cài Đặt

1. Clone repo:
   ```bash
   git clone https://github.com/username/repo.git
   ```
2. Cài đặt dependencies:
   ```bash
   npm install   # hoặc composer install,...
   ```
3. Chạy ứng dụng:
   ```bash
   npm start     # hoặc php artisan serve,...
   ```
